How to use this

  1. Open the Azure Pricing Calculator and create two saved estimates, bs-prod and bs-staging.
  2. Set region to Central India and currency to INR before adding anything — the calculator does not re-price existing rows when you change region afterwards.
  3. Walk down the production table, adding one service per row. The Configuration to enter column is written in the calculator's own fields.
  4. Repeat for staging. Add P-16 (Container Registry) to one estimate only — it is shared.
  5. Cross-check each line against the Rate column. Blue rates were read from Microsoft's retail price API for Central India; italic rates are modelled and worth confirming.

Three things the diagram is telling you

P-10 is the node that decides the budget

The HLD specifies an NC8-T4 dedicated workload profile. That meter bills at ₹589.58/hour — roughly ₹2.83 lakh per month for production alone, more than everything else on this page combined. The serverless GPU meter does the same work at ₹34.92/hour. If you take one thing from this diagram into the calculator, take this.

The environment fee is a floor, not a variable

P-04 and S-04 each bill ₹13.38/hour flat, whether or not a single container is running — about ₹19,530/month across the two environments before any workload starts. It is the price of real isolation between staging and production, and worth paying; it is not worth being surprised by.

Two nodes carry no SLA as drawn

S-03 (APIM Developer) and S-12 (Redis Basic) are single-instance tiers with no availability guarantee. That is the right call in staging. Production uses Basic v2 and Standard C1 instead — which is why P-03 and P-13 cost roughly three times their staging counterparts.

Staging can sleep

Everything in the staging Container Apps environment can scale to zero outside working hours. Halving the runtime on S-05 through S-09 takes roughly ₹7,000/month off the estimate with no loss of usefulness — the database and the environment fee are what keep running.

One Front Door could serve both

S-01 is drawn as its own profile. Running staging as a second endpoint on the production profile saves the ₹3,344/month base fee, at the cost of sharing a WAF policy boundary between environments. A reasonable trade for a pilot; state it as a decision rather than letting it happen.
